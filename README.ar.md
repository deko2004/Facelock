# نظام المصادقة البيومترية

تطبيق سطح مكتب محلي لعرض التعرف على الوجوه والتحقق من الهوية بنسبة 1:1، أُعد
لمشروع أكاديمي في الأمن السيبراني. يستخدم النظام OpenCV YuNet لاكتشاف الوجوه
وSFace لاستخراج بصمة وجه من 128 بُعدًا، مع واجهة Tkinter وتخزين مشفّر للقوالب
وخط تقييم واضح.

> **عرض أكاديمي فقط.** هذا ليس نظام هوية إنتاجيًا. يتوفر فحص اختياري للتزييف
> باستخدام MiniFASNetV2 في صفحة الكاميرا المباشرة، لكنه عرض توضيحي وليس ضمانًا
> ضد جميع هجمات العرض التقديمي أو ضمانًا معتمدًا للحيوية. لا توجد معايرة تشغيلية
> للعتبة ولا تقييم معتمد للتحيز. لا تستخدمه لحماية حسابات أو مبانٍ أو بيانات
> حساسة.

## الميزات

- **مقارنة صورتين**: كشف الوجه في صورتين وحساب تشابه جيبي وقرار مقابل عتبة.
- **التعرف والتحقق بالكاميرا المباشرة**: وضع اسم أقرب مستخدم مسجل فوق الوجه،
  مع إمكانية إجراء تحقق 1:1 مقابل مستخدم محدد.
- **حماية اختيارية من التزييف**: تفعيل MiniFASNetV2 في صفحة الكاميرا المباشرة؛
  يجب أن يمر الوجه الأكبر بفحص حيوية زمني قبل تحقق SFace.
- **تسجيل المستخدمين**: إنشاء قالب مشفّر من صورة مرفوعة أو إطار كاميرا، مع
  اشتراط الموافقة وعدم حفظ الصورة الأصلية.
- **قاعدة البيانات**: عرض المستخدمين والبحث والحذف وسجل أحداث غير بيومتري.
- **التقييم**: حساب أزواج الأصيل/المزيف ومعدلات FAR/FRR والدقة ومنحنى العتبة،
  وتصدير CSV وصورة PNG.
- **صفحة الأمان والخصوصية**: شرح نموذج التهديد، وعرض تعليمي محدود لهجوم بصورة
  ثابتة.
- **صفحة حول المشروع**: الأهداف والتقنيات وتحليل مكتبة Facelock وإخلاء
  المسؤولية الأكاديمي.
- **معالجة محلية فقط**: لا اتصال بالشبكة ولا خدمات سحابية ولا قياسات عن بُعد.

## البدء السريع

تم الاختبار على Pop!_OS 22.04 مع Python 3.12 وOpenCV 5.0.0 وTkinter 8.6 وكاميرا
`/dev/video0`.

```bash
cd /home/deku/FaceRecognitionProject
./run.sh --check     # التحقق من النماذج وقاعدة البيانات والعتبة
./run.sh             # تشغيل الواجهة
```

يقوم `run.sh` بإنشاء `venv/` عند الحاجة، وتثبيت الحزم الناقصة، والتحقق من وجود
ملفات ONNX، ثم تشغيل التطبيق. لا يعدّل النماذج ولا بياناتك المسجلة.

## النماذج المطلوبة

```text
models/face_detection_yunet_2023mar.onnx
models/face_recognition_sface_2021dec.onnx
```

وهي من [OpenCV Zoo](https://github.com/opencv/opencv_zoo). يمكن تنزيلها بالأوامر:

```bash
mkdir -p models
curl -L -o models/face_detection_yunet_2023mar.onnx \
  https://github.com/opencv/opencv_zoo/raw/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx
curl -L -o models/face_recognition_sface_2021dec.onnx \
  https://github.com/opencv/opencv_zoo/raw/main/models/face_recognition_sface/face_recognition_sface_2021dec.onnx
```

نموذج الحماية الاختياري من التزييف موجود في:

```text
models/anti_spoofing/MiniFASNetV2.onnx
```

إذا كان مفقودًا، يبدأ التطبيق وتعمل الحماية OFF. لاستعادته:

```bash
mkdir -p models/anti_spoofing
curl -L -o models/anti_spoofing/MiniFASNetV2.onnx \
  https://github.com/yakhyo/face-anti-spoofing/releases/download/weights/MiniFASNetV2.onnx
```

بصمة SHA-256:
`b32929adc2d9c34b9486f8c4c7bc97c1b69bc0ea9befefc380e4faae4e463907`.
التفاصيل والترخيص في `models/anti_spoofing/README.md`.

## سير العمل

1. افتح **Register User**، وأدخل معرّف المستخدم والاسم، ووافق على التسجيل، ثم
   اختر صورة أو التقط إطارًا من الكاميرا.
2. افتح **Verify Identity**، واختر المستخدم، ثم قارن صورة أو إطار كاميرا.
3. في **Live Camera**، فعّل **Anti-Spoofing Protection** لطلب فحص حيوية قبل
   تحقق SFace. يعمل التبديل دون إعادة تشغيل الكاميرا. إذا كان النموذج أو
   `onnxruntime` غير متوفر، تظهر رسالة خطأ وتُحجب المصادقة أثناء بقاء الخيار
   مفعّلًا.
4. افتح **Compare Two Images** لمقارنة صورتين دون تسجيل مسبق.
5. استخدم **User Database** لمراجعة المستخدمين أو حذفهم. الحذف يزيل القالب
   المشفّر ويكتب حدثًا في السجل.
6. استخدم **Evaluation & Metrics** مع مجلد بالشكل
   `dataset/<identity>/<image files>`.

العتبة الافتراضية هي `0.363`، وهي قيمة مرجعية منشورة من OpenCV لمعايرة SFace
على LFW. ليست عتبة معايرة لهذا التطبيق. يمكن تغييرها من الواجهة وتُحفظ محليًا.

## نتيجة التقييم التجريبية

يتضمن المشروع عينة عامة صغيرة من أمثلة `ageitgey/face_recognition` داخل
`images/eval_demo/`. تحتوي على 4 هويات و5 صور صالحة، لذلك فهي اختبار خط أنابيب
فقط وليست مقياسًا للأداء الحقيقي.

```bash
venv/bin/python scripts/run_evaluation.py
```

النتيجة المرصودة عند العتبة `0.363`:

```text
Identities: 4  usable images: 5
Genuine pairs: 1  impostor pairs: 9
Confusion matrix: TP=1 FN=0 FP=0 TN=9
FAR: 0.00%  FRR: 0.00%
Accuracy: 100.00%
WARNING: This is a very small sample. Treat the metrics as a pipeline smoke
test, not as a biometric performance claim.
```

تُكتب النتائج في `results/evaluation/`:

- `pairs.csv`: صف لكل مقارنة.
- `summary.csv`: المقاييس والتحذيرات.
- `far_frr_chart.png`: منحنى FAR/FRR مقابل العتبة.

هذه العينة الصغيرة لا تثبت دقة حقيقية. راجع النسخة الإنجليزية
[docs/evaluation.md](docs/evaluation.md) للتفاصيل الكاملة.

## الأمان والخصوصية

- تُشفّر القوالب المخزنة باستخدام Fernet (AES-128-CBC + HMAC-SHA256).
- يُخزّن المفتاح منفصلًا في `database/templates.key` بصلاحيات `0600`، وقاعدة
  البيانات بصلاحيات `0600` والمجلد `0700`.
- لا تُحفظ صور التسجيل في قاعدة البيانات؛ يُحفظ القالب المشفّر فقط مع بيانات
  وصفية أساسية.
- يتم التحقق من معرّفات المستخدمين ضمن مجموعة ASCII آمنة.
- سجل الأحداث يحتوي على نوع العملية والنتيجة والدرجة، وليس الصور أو المتجهات.
- لا توجد اتصالات شبكية.
- التشفير عند التخزين لا يحمي من البرمجيات الخبيثة أو حساب مستخدم مخترق أو من
  يستطيع قراءة مجلد المشروع كاملًا أو عملية تعمل بنفس صلاحيات المستخدم.

نموذج التهديد الكامل في
[docs/security_privacy.md](docs/security_privacy.md).

## الاختبارات

```bash
venv/bin/python -m pytest
```

النتيجة الحالية: **117 اختبارًا ناجحًا**. تغطي الاختبارات تحميل النماذج والكشف
وفحص الجودة وحسابات التشابه وأسماء التعرف 1:N والتشفير وقاعدة البيانات والتسجيل
والتحقق والتقييم ودورة حياة الكاميرا (بمحاكاة) وتخزين أحدث إطار وتشخيصات الأداء
وجدولة خيط المعالجة والإعدادات وبناء صفحات الواجهة، إضافة إلى معالجة PAD
والتصنيف الزمني ومنع SFace عند كشف التزييف. لا تحتاج
الاختبارات إلى كاميرا حقيقية. اختبار الواجهة يُتخطى تلقائيًا عند غياب شاشة
رسومية.

## بنية المشروع

```text
config/       الإعدادات والمسارات وحفظ العتبة
core/         الكشف والتضمين والمطابقة والتخزين والتسجيل والتحقق والتقييم والكاميرا
gui/          صفحات Tkinter والأنماط والعناصر وخيط عمل الكاميرا
models/       نماذج YuNet وSFace وMiniFASNetV2 الاختياري بصيغة ONNX
images/       صور تجريبية وعينة تقييم عامة صغيرة
database/     قاعدة SQLite المحلية ومفتاح التشفير (مستثناة من git)
results/      مخرجات التقييم المولدة
scripts/      أداة تشغيل التقييم من سطر الأوامر
tests/        اختبارات pytest
docs/         الإعداد والاستخدام والبنية والأمان والتقييم واختيار الأدوات
```

## القيود

- كشف هجمات العرض التقديمي اختياري وليس ضمانًا ضد جميع الهجمات؛ عتباته غير
  معايرة لكل كاميرا أو شاشة أو طابعة.
- لا يوجد تقييم للتحيز الديموغرافي؛ العينة صغيرة وغير ممثلة.
- العتبة غير معايرة على مجموعة تحقق.
- القوالب محمية عند التخزين لكنها تُفكّ في ذاكرة العملية أثناء المطابقة.
- قاعدة البيانات تحفظ الأسماء في نص واضح؛ القوالب البيومترية فقط مشفرة.
- صلاحيات الملفات وحساب نظام التشغيل جزء من حدود الأمان.
- مسار الكاميرا يفترض Linux/V4L2 وقد يحتاج تغييرات على أنظمة أخرى.
